# BankPulse workbook

Download `BankPulse.xlsx` and open in a recent Excel version supporting XLOOKUP. Nine sheets separate presentation, calculations, source data, assumptions and acceptance testing.

- **Analysis!B4** selects a product; SUMIFS feeds the monthly totals and weighted timely-response rate.
- **Capacity!B9:B12** contains editable staffing assumptions. Zero reviewers is valid; blank/invalid inputs produce an unavailable result.
- **Detail** contains the newest 500 complete-month records, with source IDs as text and XLOOKUP into a simulated team mapping.
- **Pivot Analysis** contains native OOXML PivotTable and product slicer parts backed by all 48 monthly product aggregates. The chart reads the pivot output range.
- **UAT** has 24 cases with expected results, actual results, status, reviewer and evidence columns. Human statuses start Not run.
- Analysis and Capacity formula cells are protected against accidental edits, without a password. This is not an access-security feature.

## Verification boundary

The authoring engine recalculated formulas and tested product selection, zero/blank capacity inputs and lookup changes. All nine sheets were rendered for visual inspection. The exported package was checked for formula error values, stored totals, valid relationships, cache record counts, chart links and unlocked input styles. See `reports/excel_verification.json` and `tests/test_excel_package.py`.

**Desktop Excel opening, refresh and slicer interaction have not been tested.** macOS Computer Use permissions remained unavailable when retried. Native feature presence is not proof of desktop interoperability. A human reviewer should execute the workbook UAT cases in Excel before marking them passed. The formula-based Analysis selector is independent of the pivot.

## Build provenance

`build_workbook.mjs` authors tables, formulas, styling, validation and charts with OpenAI's `@oai/artifact-tool`. It needs an environment where that authoring package is available; it is not required to run the dashboard or use the delivered workbook. `native_features.py` then adds native Open XML pivot/slicer parts and formula-cell protection (Python dependency: lxml). These two stages must run in this order:

```bash
node excel/build_workbook.mjs
python excel/native_features.py
python -m pytest tests/test_excel_package.py -q
```

The builder reads `inputs.json` generated by the offline pipeline and `uat.json`. Preview images default to `excel/previews/`, which is ignored. Rebuilding resets workbook input controls and UAT entries, so preserve any human-edited workbook separately. Do not run the native-feature stage twice on the same exported file.

Native parts follow Microsoft's SpreadsheetML/Open XML formats. They are checked structurally but are not advertised as desktop-validated features.
